# Changelog

## 2.0.1 - 2026-11-23

### Fixed

- Windows and macOS CI portability:
  - checkpoint file-mode assertions now respect Windows ACL semantics;
  - attack timing uses `perf_counter` so very fast runs report a non-zero rate;
  - auto-detection rejects ambiguous base64 `-nosalt` OpenSSL input instead of
    treating the encoded text as raw ciphertext;
  - the time-limit test tolerates coverage/import startup on slow runners.
- Ubuntu Python 3.9 CI uses Ubuntu 22.04, where that interpreter is available.

## 2.0.0 - 2026-11-23

Complete rewrite. The 1.x tool ("AES-Breaker" single script) is superseded.

### Added

- Byte-level parsers and verifiers for:
  - AES Crypt v1/v2/v3: ACKDF-SHA-256 for v1/v2, PBKDF2-HMAC-SHA512 for v3,
    HMAC-SHA256 password check, authenticated PKCS#7 for v3, legacy `fs16`
    reporting for v1/v2. v2 is written by default; v3 can be written with
    `encrypt --aescrypt-version 3`.
  - OpenSSL `enc`: salted and `-nosalt`, EVP_BytesToKey and PBKDF2, MD5/SHA-1/
    SHA-2 digests, AES-128/192/256 CBC/ECB/CFB1/CFB8/CFB128/OFB/CTR, and
    `-nopad`.
  - WinZip AES AE-1/AE-2: PBKDF2-SHA1/1000, 2-byte prefilter, HMAC-SHA1 auth
    code, AES-128/192/256-CTR, Zip64 and self-extractor offset handling.
- Attack sources: binary-safe wordlists (compressed wordlists supported), stdin,
  hashcat-style rules with bundled presets, masks with `?l ?u ?d ?s ?a ?h ?H`
  and `?1`..`?4` custom charsets, increment mode, hybrid masks, and two-list
  combinators.
- Multiprocessing engine with early stop, accurate counters, progress/ETA,
  configurable batch size, and safe shutdown. Workers never write output files.
- Safe output: atomic file writes, overwrite protection, ZIP path-traversal and
  symlink refusal, a configurable extraction size limit, and partial-extraction
  errors surfaced with exit code 3.
- Commands: `crack`, `decrypt`, `inspect`, `analyze`, `derive`, `encrypt`,
  `cribdrag`, `recover-iv`, `infer`, `selftest`.
- Raw AES decryption with explicit key/IV/nonce/tag, strict PKCS#7, and GCM tag
  verification.
- **Checkpoint/resume and runtime limits** for long attacks: `--checkpoint`,
  `--resume`, and `--max-runtime` (exit 124). Checkpoints are signed against the
  input, plan, verifier, rules, and spec; no password is stored.
- **Custom/headerless AES cracking** with an explicit JSON spec: PBKDF2,
  EVP_BytesToKey, scrypt, HKDF, or optional Argon2id; CBC/ECB/CTR/CFB1/CFB8/
  CFB128/OFB/GCM; explicit/embedded/derived IV; base64/hex/raw input; and a
  required real oracle (known prefix ≥8 bytes, known 16-byte block, or GCM
  tag). No-oracle heuristic mode is opt-in and can never report `confirmed`.
  A versioned JSON Schema and runnable template are included; the same spec
  can write a blob with `encrypt --format custom`.
- `infer` ranks mode/IV interpretations and reports `confirmed` only for GCM
  tags or exact known plaintext prefixes of at least 8 bytes; shorter prefixes
  and padding-only results are `probable`/`weak`.
- OpenSSL validation policies (`auto`, `strict`, `text`, `magic`, `any`), known
  plaintext prefixes, and explicit confidence labels.
- Automatic base64 decoding for recognized AES Crypt, WinZip AES, and OpenSSL
  `Salted__` inputs; custom blobs can be written from the same JSON spec with
  `encrypt --format custom --spec`.
- Machine-readable `--json`/`--json-out` output for every reporting command.
- Built-in self-test with NIST AES vectors and fixtures generated by the real
  pyAesCrypt, OpenSSL, and 7-Zip implementations, plus optional live
  interoperability checks.
- 300+ pytest tests, ruff configuration, mypy, pre-commit, coverage, a
  three-OS/Python 3.9–3.14 CI matrix, and wheel/sdist/twine packaging checks.
- The self-test includes AES Crypt v3, custom-spec CBC, and GCM checks
  (40 checks total).
- Output hardening: side outputs (`--json-out`, `--password-out`) cannot
  clobber inputs or the primary output; multiple stdout writers are rejected;
  stdout plaintext is spooled until authentication/padding succeeds.

### Changed

- The package is installable (`pip install .`) and exposes the `aesbreaker`
  console command.
- Requirements are Python 3.9+ and pycryptodome; pyAesCrypt is now only a
  development/test dependency.
- Documentation rewritten, including exact wire formats in `docs/formats.md`.

### Removed

- The legacy text mode (`--decrypt`/`--key`) that tried unauthenticated modes
  with zero IVs and selected the "most readable" output.
- The GCM fallback that decrypted without verifying the tag.
- Silent key padding/truncation and the unused MD5 `derive_key` helper.
- Temp-file-per-attempt dictionary attack logic and its whitespace-stripping
  wordlist handling.
- The old `--blob`/`--zip` file-mode flags. Use the new commands; ZIP AES
  archives are handled natively and verified with their auth code.

## 1.0.0

Initial single-file release: pyAesCrypt dictionary attacks and a heuristic
